# Менеджер контактов

Консольное приложение на Python: добавление, редактирование, удаление, поиск и группировка контактов. СРО №15 по дисциплине «Языки и технология программирования».

## Проблема и аудитория
Контакты разбросаны по разным сервисам, возникают дубликаты и трудности с поиском. Приложение предназначено для студентов и преподавателей, которым нужна простая локальная адресная книга.

## Анализ аналогов
Google Контакты, контакты iOS/Android, Outlook «Люди». Подробности и ссылки в `docs/REPORT.md`.

## Возможности
- добавление с проверкой имени, телефона, e-mail, группы;
- редактирование отдельных полей;
- удаление с подтверждением;
- поиск по имени, телефону и e-mail;
- группировка по группам (Семья, Друзья, Работа, Учёба, Другое);
- сохранение в `contacts.json`.

**Ограничения:** консольный интерфейс, один пользователь, упрощённая проверка e-mail, без импорта/экспорта.

## Стек и структура
Python 3.10+, только стандартная библиотека.
```

```
