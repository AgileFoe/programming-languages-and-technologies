# Лабораторная работа №9
## Асинхронные запросы (Fetch API, AJAX)

**Дисциплина:** Языки и технология программирования  
**Вариант:** 17 — Интерфейс «Пользователь — публикации — комментарии»

## 1. Цель работы

Изучить механизм выполнения асинхронных HTTP-запросов с помощью Fetch API. Научиться получать данные из публичного REST API, обрабатывать JSON-ответы, динамически отображать информацию на веб-странице и обрабатывать ошибки загрузки.

## 2. Постановка задачи

Необходимо разработать веб-приложение, которое позволяет:

1. Получать информацию о пользователе по его ID.
2. Загружать список публикаций выбранного пользователя.
3. Получать комментарии к выбранной публикации.
4. Отображать данные без перезагрузки страницы.
5. Показывать состояния загрузки, успешного выполнения и ошибки.
6. Использовать `fetch()`, `async/await`, `response.ok`, `try/catch/finally`.
7. Безопасно выводить полученные данные в DOM.

## 3. Используемые технологии

- **HTML5** — создание структуры страницы.
- **CSS3** — оформление интерфейса и адаптация к размеру экрана.
- **JavaScript** — обработка действий пользователя и управление отображением данных.
- **Fetch API** — отправка HTTP-запросов.
- **JSONPlaceholder** — публичный учебный REST API.
- **Live Server** — локальный запуск проекта.

## 4. Анализ используемого API

В работе используется сервис JSONPlaceholder, предоставляющий демонстрационные данные для обучения.

Адрес API: https://jsonplaceholder.typicode.com/

В приложении используются следующие конечные точки (endpoints):

| Запрос | Назначение |
|---|---|
| `GET /users/{id}` | Получение информации о пользователе |
| `GET /posts?userId={id}` | Получение публикаций пользователя |
| `GET /posts/{id}/comments` | Получение комментариев к публикации |

### Структура данных

Объект пользователя содержит идентификатор, имя, электронную почту, адрес и информацию о компании.

Пример JSON-ответа:

```json
{
  "id": 1,
  "name": "Leanne Graham",
  "email": "Sincere@april.biz",
  "address": {
    "city": "Gwenborough"
  },
  "company": {
    "name": "Romaguera-Crona"
  }
}
```
Публикация содержит поля id, userId, title и body.

Комментарий содержит поля postId, id, name, email и body.

Полученные JSON-данные преобразуются в объекты JavaScript с помощью метода response.json().

## 5. Описание работы приложения
5.1. Получение пользователя
Пользователь вводит ID от 1 до 10 и нажимает кнопку «Найти». Программа проверяет введённое значение и отправляет GET-запрос к /users/{id}.

После получения ответа отображаются имя пользователя, электронная почта, город и название компании.

5.2. Получение публикаций
После успешной загрузки пользователя приложение отправляет запрос /posts?userId={id}.

Полученные публикации отображаются в виде компактного списка. Для каждой публикации предусмотрена кнопка «Комментарии».

5.3. Получение комментариев
При нажатии кнопки «Комментарии» отправляется запрос /posts/{id}/comments.

После успешного ответа на странице отображаются заголовки комментариев, электронные адреса авторов и тексты сообщений.

5.4. Обработка ошибок
Перед обработкой данных проверяется свойство response.ok. Для обработки исключений используется конструкция try/catch, а finally применяется для повторного включения кнопки загрузки пользователя.

Во время выполнения запросов интерфейс отображает сообщения о загрузке. При ошибках выводится соответствующее сообщение.

## 6. Алгоритм работы
Последовательность действий приложения:

Пользователь вводит ID.

JavaScript проверяет введённое значение.

Выполняется запрос пользователя.

Ответ преобразуется из JSON в объект JavaScript.

Данные пользователя отображаются в DOM.

Выполняется запрос публикаций выбранного пользователя.

Публикации отображаются на странице.

Пользователь выбирает публикацию.

Выполняется запрос комментариев.

Комментарии отображаются на странице.

Схема процесса:

Действие пользователя → HTTP-запрос → Ответ сервера → Обработка JSON → Обновление DOM.

## Контрольные вопросы
#### 1. Что такое AJAX?

            AJAX — подход к обмену данными с сервером без полной перезагрузки веб-страницы. 

#### 2. Что такое REST API?

            REST API — интерфейс взаимодействия с ресурсами сервера через HTTP-запросы.

#### 3. Что возвращает fetch()?

            fetch() возвращает Promise, который при успешном выполнении запроса позволяет получить объект Response.

#### 4. Для чего используются async и await?

            Они позволяют удобно работать с асинхронными операциями и ожидать их завершения.

#### 5. Для чего нужна проверка response.ok?

            Она позволяет определить, был ли получен успешный HTTP-ответ. Например, ответ со статусом 404 сам по себе обычно не вызывает переход в catch.

#### 6. Что делает response.json()?

            Преобразует тело ответа в JavaScript-значение, например объект или массив.

#### 7. Как обрабатываются ошибки?

            Для перехвата исключений используется try/catch. HTTP-ошибки проверяются отдельно через response.ok.

#### 8. Что такое DOM?

            DOM — объектное представление HTML-документа, позволяющее JavaScript изменять содержимое страницы.

#### 9. Что такое CORS?

            CORS — механизм браузерной безопасности, регулирующий доступ веб-страниц к ресурсам с других источников.

#### 10. Почему используется textContent?

            Он позволяет вставлять данные как обычный текст, не интерпретируя их как HTML-разметку.
