# Задание №4 — Блок заметок

## Описание

Необходимо создать блок заметок, в котором пользователь может ввести текст и добавить его в список. Каждая созданная заметка должна иметь кнопку удаления.

## Реализованные возможности

В приложении реализованы:

1. Поле для ввода текста.
2. Кнопка «Добавить».
3. Добавление новой заметки в список.
4. Кнопка «Удалить» для каждой заметки.
5. Проверка пустого ввода.
6. Добавление заметки нажатием клавиши `Enter`.

## Принцип работы

После нажатия кнопки «Добавить» JavaScript получает значение из поля ввода с помощью:

```javascript
noteInput.value


Затем создаётся новый HTML-элемент:

document.createElement("li")


В него добавляется текст заметки и кнопка удаления.

Для удаления используется метод:

li.remove()

Таким образом, пользователь может динамически добавлять и удалять элементы списка без перезагрузки страницы.
```

# Задание №19 — Корзина интернет-магазина
Описание

Необходимо создать экран корзины интернет-магазина с возможностью изменять количество товаров, удалять позиции и автоматически пересчитывать количество товаров и общую стоимость.

Реализованные возможности

В приложении реализованы:

Отображение списка товаров.

Название и цена каждого товара.

Изменение количества товара.

Увеличение количества кнопкой +.

Уменьшение количества кнопкой −.

Установка количества товара в 0.

Возможность повторно добавить товар после его удаления.

Пересчёт стоимости каждого товара.

Пересчёт общего количества товаров.

Пересчёт общей стоимости корзины.

Отображение сообщения о пустой корзине.

Структура данных

Товары хранятся в массиве объектов:

```javascript
let cart = [
    {
        id: 1,
        name: "Ноутбук",
        price: 350000,
        quantity: 1,
        image: "💻"
    },
    {
        id: 2,
        name: "Наушники",
        price: 25000,
        quantity: 2,
        image: "🎧"
    },
    {
        id: 3,
        name: "Мышь",
        price: 12000,
        quantity: 1,
        image: "🖱️"
    }
];


Каждый товар содержит:

id — уникальный идентификатор;

name — название;

price — стоимость одной единицы;

quantity — количество;

image — изображение товара.

Изменение количества

Для изменения количества используется функция:

function changeQuantity(id, change)


Она находит необходимый товар и изменяет его количество.

Если количество становится меньше нуля, оно устанавливается обратно в 0:

if (item.quantity < 0) {
    item.quantity = 0;
}


После каждого изменения вызывается:

renderCart();


Это позволяет сразу обновить информацию на странице.

Удаление товара

Вместо полного удаления товара из массива используется установка количества в 0:

function removeItem(id) {
    const item = cart.find(function(product) {
        return product.id === id;
    });

    if (!item) {
        return;
    }

    item.quantity = 0;

    renderCart();
}


Такой подход позволяет сохранить товар в корзине и добавить его повторно.

Повторное добавление товара

Если количество товара равно 0, пользователю отображается кнопка «Добавить».

При нажатии вызывается функция:

function restoreItem(id) {
    const item = cart.find(function(product) {
        return product.id === id;
    });

    if (!item) {
        return;
    }

    if (item.quantity === 0) {
        item.quantity = 1;
    }

    renderCart();
}


Таким образом, товар можно удалить из текущего заказа, а затем снова добавить его без перезагрузки страницы.

Пересчёт общей суммы

Общее количество товаров и стоимость рассчитываются автоматически:

let quantitySum = 0;
let priceSum = 0;

cart.forEach(function(item) {
    quantitySum += item.quantity;
    priceSum += item.price * item.quantity;
});


После этого значения выводятся на страницу:

totalQuantity.textContent = quantitySum;
totalPrice.textContent = formatPrice(priceSum);



Это обеспечивает обновление корзины в реальном времени.
```
