# Задание 5. Таблица умножения

## Постановка задачи

Создать программу, которая получает от пользователя число от 1 до 10 и с помощью цикла выводит таблицу умножения для этого числа.

## Реализация

Для получения числа используется поле `input`.

После нажатия кнопки запускается функция `multiplication()`.

С помощью цикла `for` выполняется умножение введённого числа на числа от 1 до 10.

```javascript
function multiplication() {

    let number =
        Number(document.getElementById("number").value);

    let result =
        document.getElementById("result");

    if (number < 1 || number > 10) {
        result.innerHTML =
            "Введите число от 1 до 10";
        return;
    }

    result.innerHTML = "";

    for (let i = 1; i <= 10; i++) {
        result.innerHTML +=
            `${number} × ${i} = ${number * i}<br>`;
    }
}

Результат

Пользователь вводит число, например 5, после чего программа выводит:

5 × 1 = 5
5 × 2 = 10
5 × 3 = 15
5 × 4 = 20
5 × 5 = 25
5 × 6 = 30
5 × 7 = 35
5 × 8 = 40
5 × 9 = 45
5 × 10 = 50

```

# Задание 9. Проверка пароля
Постановка задачи

Создать форму проверки пароля.

Пароль должен соответствовать двум условиям:

Содержать минимум 8 символов.

Содержать хотя бы одну цифру.

Программа должна показать, выполнено ли каждое условие.

Реализация

Для проверки длины используется свойство length.

Для поиска цифры используется регулярное выражение:

```javascript
/\d/


Основная функция:

function checkPassword() {

    let password =
        document.getElementById("password").value;

    let result =
        document.getElementById("result");

    let lengthOk =
        password.length >= 8;

    let digitOk =
        /\d/.test(password);

    result.innerHTML = `
        <p>
            ${lengthOk ? "✅" : "❌"}
            Длина минимум 8 символов
        </p>

        <p>
            ${digitOk ? "✅" : "❌"}
            Есть цифра
        </p>

        <p>
            ${
                lengthOk && digitOk
                ? "✅ Пароль подходит"
                : "❌ Пароль не подходит"
            }
        </p>
    `;
}

Результат

Например, если пользователь вводит:

password123


то программа сообщает:

✅ Длина минимум 8 символов
✅ Есть цифра
✅ Пароль подходит


Если введён пароль:

hello


то результат будет:

❌ Длина минимум 8 символов
❌ Есть цифра
❌ Пароль не подходит

```

# Задание 18. Электронный журнал
Постановка задачи

Создать электронный журнал студентов.

В журнале должны отображаться:

имена студентов;

названия предметов;

оценки;

средний балл каждого студента.

Дополнительно реализована возможность редактирования данных.

Структура данных

Информация о предметах хранится в массиве:

```javascript

let subjects = [
    "Математика",
    "Информатика",
    "История"
];


Студенты представлены в виде массива объектов:

let students = [
    {
        name: "Иван",
        grades: [5, 4, 5]
    },

    {
        name: "Анна",
        grades: [5, 5, 4]
    },

    {
        name: "Петр",
        grades: [3, 4, 3]
    }
];


Каждый объект содержит имя студента и массив его оценок.

Создание таблицы

Таблица создаётся динамически с помощью JavaScript и DOM.

Используются методы:

document.createElement()


и

table.insertRow()


Также создаются отдельные ячейки:

row.insertCell()


Таким образом, таблица не прописывается полностью в HTML, а формируется программно.

Вычисление среднего балла

Для каждого студента программа складывает все его оценки:

let sum = 0;

student.grades.forEach(function(grade) {
    sum += Number(grade);
});


Затем сумма делится на количество оценок:

let average =
    sum / student.grades.length;


Для отображения двух знаков после запятой используется:

average.toFixed(2);

Редактирование предметов

Пользователь может изменить название предмета непосредственно в поле.

Например:

Математика


можно изменить на:

Алгебра


Для этого используется функция:

function changeSubject(index, newName) {

    if (newName.trim() === "") {
        alert("Название предмета не может быть пустым");
        renderSubjects();
        return;
    }

    subjects[index] = newName;

    renderTable();

Добавление предмета

Новый предмет можно добавить с помощью кнопки:

+ Добавить предмет


После добавления предмета каждому студенту автоматически добавляется новая оценка.

subjects.push(name);

students.forEach(function(student) {
    student.grades.push(0);
});

Удаление предмета

Предмет можно удалить кнопкой X.

При удалении предмета соответствующая оценка удаляется у каждого студента:

subjects.splice(index, 1);

students.forEach(function(student) {
    student.grades.splice(index, 1);
});

Редактирование оценок

Каждая оценка представлена полем input.

Пользователь может изменить оценку от 1 до 5.

После изменения выполняется функция:

function changeGrade(
    studentIndex,
    gradeIndex,
    value
) {
    let grade = Number(value);

    if (grade < 1 || grade > 5) {
        alert("Оценка должна быть от 1 до 5");
        renderTable();
        return;
    }

    students[studentIndex]
        .grades[gradeIndex] = grade;

    renderTable();
}


После изменения оценки средний балл пересчитывается автоматически.

Добавление и удаление студентов

Также реализована возможность добавлять новых студентов:
```
