Индивидуальное задание №7
Условие

Ввести количество минут. Определить количество полных часов и оставшихся минут.

Входные данные
minutes — количество минут, целое число.
Выходные данные
количество полных часов;
количество оставшихся минут.
Алгоритм решения
Ввести количество минут.
С помощью оператора // разделить количество минут на 60 и получить количество полных часов.
С помощью оператора % найти остаток от деления на 60.
Вывести количество часов и оставшихся минут.
Исходный код
minutes = int(input("введите количество минут:"))

hours = minutes // 60
rem = minutes % 60

print(f"часов: {hours}", f"минут: {rem}")

Результат выполнения

Пример:

введите количество минут: 125
часов: 2 минут: 5

Тестовые примеры
№	Входные данные	Часы	Минуты
1	125	2	5
2	60	1	0
3	245	4	5
Вывод

В ходе выполнения задания была разработана программа, которая преобразует заданное количество минут в количество полных часов и оставшихся минут. В программе использовались функции input() и print(), преобразование типа int(), а также арифметические операторы // и %.

Индивидуальное задание №14
Условие

Ввести массу в килограммах и рост в метрах. Вычислить индекс массы тела:
BMI = масса / рост².

В программе рост вводится в сантиметрах и затем переводится в метры.

Входные данные
mass — масса человека в килограммах;
height — рост человека в сантиметрах.
Выходные данные
индекс массы тела (BMI).
Алгоритм решения
Ввести массу человека в килограммах.
Ввести рост человека в сантиметрах.
Перевести рост из сантиметров в метры, разделив его на 100.
Возвести полученный рост в квадрат.
Разделить массу на квадрат роста.
Вывести полученное значение BMI.
Исходный код
mass = int(input("введите массу: "))
height = int(input("введите рост: "))

conv = height / 100
BMI = mass / (conv * conv)

print(f"индекс массы тела: {BMI}")

Результат выполнения

Пример:

введите массу: 70
введите рост: 175
индекс массы тела: 22.857142857142858

Тестовые примеры
№	Масса, кг	Рост, см	BMI
1	70	175	22.86
2	80	180	24.69
3	60	170	20.76
Вывод

В ходе выполнения задания была разработана программа для вычисления индекса массы тела. В программе использовались переменные, функции input() и print(), преобразование введённых данных с помощью int(), а также арифметические операции / и *. Дополнительно было выполнено преобразование роста из сантиметров в метры.

Индивидуальное задание №18
Условие

Ввести пятизначное число. Найти сумму его цифр и сформировать число с обратным порядком цифр. Строки и циклы не использовать.

Входные данные
num — пятизначное целое число.
Выходные данные
сумма пяти цифр числа;
число, записанное в обратном порядке.
Алгоритм решения
Ввести пятизначное число.
С помощью оператора // получить первую цифру.
С помощью операций // и % получить вторую, третью и четвёртую цифры.
С помощью оператора % получить последнюю цифру.
Сложить все пять цифр.
Сформировать число в обратном порядке, используя полученные цифры и соответствующие разряды.
Вывести сумму цифр и число в обратном порядке.
Исходный код

Примечание: в требованиях лабораторной работы указано не использовать if, поэтому проверка на пятизначность из исходного кода убрана.

num = int(input("Введите пятизначное число: "))

first = num // 10000
second = (num // 1000) % 10
third = (num // 100) % 10
fourth = (num // 10) % 10
fifth = num % 10

sum_digits = first + second + third + fourth + fifth

reverse = (fifth * 10000) + \
          (fourth * 1000) + \
          (third * 100) + \
          (second * 10) + \
          first

print(f"Сумма 5-ти цифр числа - {sum_digits}")
print(f"Обратный порядок чисел - {reverse}")

Результат выполнения

Пример:

Введите пятизначное число: 12345
Сумма 5-ти цифр числа - 15
Обратный порядок чисел - 54321

Тестовые примеры
№	Исходное число	Сумма цифр	Обратное число
1	12345	15	54321
2	54321	15	12345
3	24680	20	8642

В третьем тесте результат 8642 получается из-за того, что последняя цифра исходного числа равна 0. Число 08642 математически равно 8642.

Вывод

В ходе выполнения задания была разработана программа для обработки пятизначного числа без использования строк и циклов. Для выделения отдельных цифр были использованы операции целочисленного деления // и нахождения остатка %. На основе полученных цифр была вычислена их сумма и сформировано число в обратном порядке.

Контрольные вопросы
1. Что представляет собой переменная в Python?

Переменная — это имя, которое используется для хранения и обращения к определённому значению в программе.

Пример:

age = 18


Здесь age — переменная, содержащая значение 18.

2. Какие основные типы данных используются в Python?

К основным типам данных относятся:

int — целые числа;
float — числа с плавающей точкой;
str — строки;
bool — логический тип;
list — списки;
tuple — кортежи;
dict — словари;
set — множества.
3. Чем int отличается от float?

int используется для хранения целых чисел:

10
-5
100


float используется для хранения дробных чисел:

3.14
2.5
-0.75

4. Как работает функция input()?

Функция input() считывает данные, введённые пользователем с клавиатуры, и возвращает их в виде строки.

Пример:

name = input("Введите имя: ")

5. Почему результат input() часто необходимо преобразовывать?

Потому что функция input() возвращает строку даже в том случае, если пользователь вводит число.

Для выполнения математических операций строку необходимо преобразовать в числовой тип:

number = int(input("Введите число: "))

6. Для чего используются int() и float()?

Функция int() преобразует значение в целое число:

number = int("25")


Функция float() преобразует значение в число с плавающей точкой:

number = float("3.14")

7. Чем / отличается от //?

Оператор / выполняет обычное деление:

7 / 2


Результат:

3.5


Оператор // выполняет целочисленное деление:

7 // 2


Результат:

3

8. Что делает оператор %?

Оператор % возвращает остаток от деления.

Например:

17 % 5


Результат:

2


Также оператор % используется для получения последней цифры числа:

123 % 10


Результат:

3

9. Для чего используется оператор **?

Оператор ** используется для возведения числа в степень.

Например:

5 ** 2


Результат:

25

10. Как определить тип переменной с помощью type()?

Для определения типа переменной используется функция type():

number = 10
print(type(number))


Результат:

<class 'int'>

11. Что такое преобразование типов?

Преобразование типов — это изменение типа одного значения в другой.

Например:

number = int("25")


Строковое значение "25" преобразуется в целое число 25.

12. Что произойдёт при попытке int("Python")?

Произойдёт ошибка ValueError, потому что строку "Python" невозможно преобразовать в целое число.

13. Как получить последнюю цифру целого числа?

Для этого используется оператор %:

number % 10


Например:

123 % 10


Результат:

3

14. Как удалить последнюю цифру целого числа?

Для удаления последней цифры используется целочисленное деление на 10:

number // 10


Например:

123 // 10


Результат:

12

15. Почему выбор правильного типа данных важен?

Правильный выбор типа данных позволяет корректно хранить и обрабатывать информацию. Например, для количества предметов используется int, для дробных значений — float, а для текста — str. Неправильный выбор типа может привести к ошибкам или некорректным результатам вычислений.
